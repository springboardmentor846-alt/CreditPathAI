## Frontend Module
## Overview

- This frontend module is designed to visualize   borrower risk, recovery insights, and action recommendations generated by the CreditPathAI – Smart Loan Recovery System.

- The frontend is implemented using React.js and Recharts, following a component-based architecture to ensure clarity, scalability, and ease of demonstration during evaluation.

## Components Description
1. ChartsDashboard.js

- Displays recovery and risk analytics through interactive charts

# Visualizations include:

- Line chart for recovery percentage by loan type

- Bar chart for total cost by loan type

- Pie chart for risk distribution (Low / Medium / High)

- Heatmap-style risk visualization for customer segments

- Helps stakeholders understand portfolio-level performance and risk

2. RecommendationPanel.js

- Displays loan recovery action recommendations

- Accepts borrower loan details as input

# Outputs:

- Risk category

- Suggested recovery action

- Intended for loan recovery agents to support decision-making

3. KPI Cards (Dashboard Section)

- Displays key performance indicators:

- Total number of cases

- Total loan amount

- Total recovered amount

- Risk percentage by category

- Enables quick insight generation for business users
